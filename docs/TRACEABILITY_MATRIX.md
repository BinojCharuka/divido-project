## UI implementation note (DIV-041, 2026-11-16)

DEC-029 was approved on 2026-11-16: the Figma-based UI is the production UI. DIV-041 replaced the earlier page components with layered feature components under `frontend/features/` (see [`04-architecture/frontend-architecture.md`](04-architecture/frontend-architecture.md) §9). Requirements, API contracts and database mappings above are unchanged. The component tests named above were rewritten for the new components under the same file names (`tests/transactions.test.tsx`, `tests/management.test.tsx`, `tests/budget.test.tsx`, `tests/dashboard.test.tsx`), and the E2E specs (`e2e/*.spec.ts`) were updated to the new UI.

## Rules

- Replace planned IDs only after the canonical story/use-case register is authored.
- Every approved story must map to at least one acceptance test.
- A story that spans frontend and backend must identify both sets of tasks and its integration check.
- Update this file whenever a requirement or contract changes.
